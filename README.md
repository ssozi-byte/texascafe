# Kim’s Texas Caffe

A responsive café website for Kim’s Texas Caffe in Ndenderu, Kiambu County, Kenya.

## Features

- Strong branded landing page with a rotating hero carousel
- Featured categories and curated menu highlights
- Searchable, filterable menu section with quick-view product details
- About, offers, gallery and location/contact blocks
- Mobile-friendly navigation and responsive layout
- WhatsApp and telephone call-to-action links

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000 to view the site in the browser.

## Validate

```bash
CI=true npm test -- --watch=false
npm run build
```
